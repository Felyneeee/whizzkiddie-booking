# Whizzkids Academic Center

Setup: `npm install` then `npm run dev` (http://localhost:3000)

Admin login (application mock data in browser localStorage):
- Admin: admin / admin123

`whizzkids.db` is a separate SQLite database file that can be opened with SQLite Browser Lite or another SQLite browser. The current web app still reads and writes its application data in browser localStorage; the SQLite file is a standalone database and is not connected to the app.
